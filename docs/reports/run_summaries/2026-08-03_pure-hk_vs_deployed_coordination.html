Reading notes. Values are binned every 500 ticks and the first 900 are dropped (spawn transient). Distance is straight-line from spawn, so a robot walking in circles shows a flat line while its step rate stays high. An exactly round value (0.0000, 0.5000) is usually structural rather than measured — a frozen body or a metric whose input was gated off — not a clean result.
