# Godot brain configs

These JSON files are launcher / brain configs for the Godot host. There are two
lineages here, and they are not equal:

- **`the_cell_*`** — the **Cell** forager, Zanshin's forward-facing example. This is
  where to start. The Cell report and doctrine describe what these run.

- **`the_picrawler_*`** (and everything under `archive/`, including `BASELINES.md`) —
  the quadruped **picrawler detour**: an earlier, deliberately over-ambitious attempt
  to run the framework in a complex body *before the method was ready*. Some of these
  encode the scaffolded, reward-shaped setups the project now warns against. They are
  kept as an honest historical and experimental record — **not as recommended
  baselines, and not the way to learn this project.**

Read [`docs/the-picrawler-detour.md`](../../../../../docs/the-picrawler-detour.md) for
the full story of why the picrawler is here and why the Cell is the starting point.

Note: `archive/BASELINES.md` predates the current package layout and references the
old `ami-ogma` conda environment and scripts; treat it as a historical note, not a
working recipe.
